# Gates and evidence

Use a gate when proceeding would commit a creative lock, money, external state,
rights-sensitive material or an irreversible publication. Present a concrete
reviewable artifact before asking for approval whenever possible.

An execution gate records:

- backend and exact workflow identity;
- all inputs and their upload order;
- job count, duration and important generation parameters;
- output directory and expected file types;
- estimated cost or rental exposure;
- timeout, retry and shutdown behavior.

Evidence should match the deliverable. Examples include media duration,
resolution and codec inspection; image dimensions; document rendering; a
playback review; external job history; or a user acceptance decision. Planning
documents prove planning quality only. They do not prove the rendered result.
