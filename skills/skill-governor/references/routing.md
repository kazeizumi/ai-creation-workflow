# Routing guide

Map the task to a lane before searching names. Typical AI production lanes are:

- project control and orchestration;
- story and script development;
- direction, shots and staging;
- reference and prompt production;
- image, video, VFX, audio or voice execution;
- media inspection, edit and delivery;
- infrastructure and runtime operations.

Choose the narrowest candidate whose declared output covers the stage. A broad
orchestrator should coordinate a specialist rather than rewrite the specialist's
artifact. If no current route exists, perform a bounded discovery pass and keep
the candidate on probation until it is reviewed and tested.
